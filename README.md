# Шахматный класс

Сайт для обучения игре в шахматы. Работает полностью в браузере: без сервера, без сборки и без внешних библиотек.

## Разделы

- **Игра с ботом** — шесть уровней сложности: от «Новичка», который часто ходит наугад, до «Мастера», который думает до 4 секунд на ход. Можно играть белыми, чёрными или случайным цветом, брать ходы назад, просить подсказку и сдаваться. Незаконченная партия и статистика по уровням сохраняются в браузере.
- **Разбор ошибок** — движок проверяет каждый ход партии и помечает неточности (?!), ошибки (?) и зевки (??). Для каждого хода есть объяснение: что упущено, какую фигуру подставили, был ли мат. Ещё есть график оценки и точность каждой стороны. Можно разобрать последнюю партию против бота или вставить свою в формате PGN. Свои ошибки можно отправить в тренировку.
- **Обучение** — 17 интерактивных уроков: доска и клетки, ходы всех фигур (с упражнениями «собери пешки»), ценность фигур, рокировка, превращение, взятие на проходе, шах, мат и пат, мат ферзём и двумя ладьями против бота, вилка и связка, принципы дебюта.
- **Задачи** — мат в 1 и в 2 хода, вилки, связки, сквозной удар, вскрытое нападение, выигрыш материала. Здесь же категория «Мои ошибки» — позиции из ваших партий, где нужно найти ход сильнее сыгранного.

## Запуск

Самый простой способ — скачать один файл [`dist/chess-class.html`](dist/chess-class.html) и открыть его в браузере. В нём уже собран весь сайт, интернет не нужен. Пересобрать файл после изменений: `python3 tools/build.py`.

Можно также открыть `index.html` из папки проекта. Откройте `index.html` в браузере. Лучше запустить через любой статический сервер, тогда бот считает ходы в отдельном потоке (Web Worker) и интерфейс не подтормаживает:

```sh
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Если открыть страницу как файл, бот будет считать в основном потоке. Всё работает, но на сильных уровнях интерфейс может ненадолго замирать.

## Устройство

| Файл | Назначение |
| --- | --- |
| `js/chess.js` | Правила: генерация ходов, шах, мат, пат, рокировка, взятие на проходе, повторения, FEN и SAN |
| `js/ai.js` | Бот: оценка позиции, альфа-бета поиск с итеративным углублением, форсированные варианты, таблица транспозиций, разбор ходов |
| `js/engine.js`, `js/worker.js` | Запуск бота в Web Worker с запасным режимом |
| `js/board.js` | Доска: клик и перетаскивание, подсветка ходов, стрелки, выбор фигуры при превращении |
| `js/lessons.js`, `js/puzzles.js` | Уроки и задачи |
| `js/app.js` | Интерфейс разделов |

## Тесты

```sh
node tests/perft.js     # корректность генератора ходов (perft на эталонных позициях)
node tests/puzzles.js   # все задачи корректны, матовые действительно заканчиваются матом
node tests/lessons.js   # позиции и решения уроков допустимы
```
